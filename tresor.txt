1.Vérifier la connexion au serveur de contrôle :1 min.Ouvrez PowerShell en tant qu'administrateur et exécutez :tailscale netcheckVérification : Assurez-vous que la ligne Report: indique DERP latency et qu'aucune interdiction HTTPS/Control n'est bloquée.2.Désactiver l'expiration de la clé de la machine (Key Expiry) :1 min.Si la clé réseau a expiré, Tailscale bloque le statut dans l'interface web tout en laissant passer les paquets existants.Rendez-vous sur la console Tailscale Admin ([login.tailscale.com/admin/machines](https://login.tailscale.com/admin/machines)).Cliquez sur les trois petits points (...) à côté de votre machine Windows.Sélectionnez Disable key expiry.Vérification : Rafraîchissez la page pour voir si l'appareil repasse en Connected.3.Purger le cache et réenregistrer la machine :2 min.Si le statut de l'application reste bloqué localement :Dans PowerShell (Administrateur), coupez et relancez le client :tailscale downtailscale up --resetSi le problème persiste, supprimez l'appareil directement depuis la console web Admin Tailscale (Option Delete...).Relancez la commande tailscale up sur Windows pour recréer proprement le nœud.
